# 亚马逊八项全能精英 v1.0

免费的 Codex 亚马逊运营技能套件。本地工具源码预览版 **0.2.0**。当前能力与验证边界见下表。

一个统一入口，按目标选择八项能力：日常监控、广告诊断、Listing 优化、选品调研、库存物流、利润分析、合规初筛和运营复盘。八项是工作方法，不是八个后台自动执行的机器人。

```text
你描述需求 → Codex 按授权操作本机紫鸟 → 下载原始报表
                      ↓
              文件快照、范围与哈希校验
                      ↓
    本地 PostgreSQL：原件 + 原始行 + 指标 + HTML
                      ↓
       广告诊断报告与复核清单（不改店铺后台）
```

## 已完成与边界

| 能力 | 本候选版状态 |
|---|---|
| 统一入口＋八个专业技能 | 已提供安装源与调用说明 |
| 紫鸟取数 | Codex 本地 Computer Use 操作指南＋下载交接校验；当前 macOS 环境完成原生 SP Bulk 工作簿下载、原生 ID 与双工作表校验 |
| PostgreSQL | 已实现本机专用库初始化、事务入库、重复导入保护、原件哈希验证、报告重导出；隔离合成数据及独立真实本机库验收通过 |
| SP 广告诊断与 HTML | 活动与搜索词两表校验、归因成熟度、指标与候选；合成样例与真实原生 ID 数据完整链路通过（真实报告为观察模式） |
| 其余七项 | 可调用的专业工作流；不声称有对应的自动采集器或全自动计算管线 |
| PostgreSQL 缺失时 | macOS 已有 Homebrew 可辅助安装；先预览后明确 apply。实际下载安装分支未在本次验收执行 |
| 平台兼容 | macOS/本机 PostgreSQL 16 实测；Windows、Linux 与其他紫鸟版本未完成端到端验收 |

**需要 Codex 环境提供本地应用操作工具。** CLI 不会独立点击紫鸟，不是安装后脱离 Codex 自动运行的爬虫。缺少 Computer Use 时支持用户手工导出文件。店铺登录、密码、验证码由用户在本机处理，不采集 Cookie。

真实平台导出可能没有稳定活动/广告组 ID，或缺活动报表。程序会停止并列缺口；需要从受支持来源补齐并核实，不能按活动同名自动合并。原生 Bulk 双工作表已完成真实取数、入库与报告验收。经营时区、Bulk 归因口径和业务阈值未全部确认时仅观察；优化效果仍为 **pending**。

## 开始使用

完整步骤见 **[安装说明](docs/INSTALL.md)**；图解见 **[公开版操作手册](docs/guide.html)**，报告示例见 **[合成广告诊断 HTML](docs/demo-report.html)**。首次建议运行合成样例，确认环境和报告。

```sh
# 在这个完整源目录中执行；Python >= 3.11
python3 -m aee doctor
python3 -m aee --help

# 预览技能安装（路径由你选择；已有同名技能不会覆盖）
python3 -m aee install-skills --target "$HOME/.codex/skills"
# 确认后再加 --apply
```

**安装完成提醒：** 卖家精灵和SIF已有官方MCP，现提供本地Key配置向导。运行 `python3 -m aee research-mcp-ui` 预览，再加 `--apply`，打开本机浏览器密码框填写自己的Key；另保留 `research-mcp` 终端入口。详见[选品MCP接入说明](docs/RESEARCH_MCP.md)。配置后需刷新客户端并验证鉴权；未取得Key前不声称已连接。

安装后在 Codex 输入：

> 亚马逊八项全能精英v1.0：先检查本地环境，打开紫鸟列出可访问店铺供我选择。确认站点和日期后，下载广告资料，校验后保存到我确认的本机 PostgreSQL，生成广告诊断 HTML，标清数据日期和资料缺口，先不要改店铺后台。

本包不预置店铺、服务器、账号或凭据；默认不发布、不发送、不排期。

## 数据与隐私

- 首版把原始广告文件 **bytea**、原始行 **JSONB**、分析结果和 HTML 都保存在本地 PostgreSQL；本地导出副本用于查看。不连接远程数据库。
- 每个批次记录来源、店铺、站点、期间、生成/采集时刻、文件名与 SHA-256。历史版本保留，不把重复快照相加。
- 限制：每文件 20MiB、10万数据行、256列；XLSX 最多32工作表，解压总量100MiB、单项50MiB。超限停止，不静默截断。
- 报告、下载、数据库配置及运行结果写入你自己的私有目录；不提交到公开仓库。建议保持目录仅当前用户可读。
- 本地存储不等于本地推理：提交给云端 Codex 模型分析的资料仍涉及模型服务。工具本身不提供遥测、云同步或上传接口。
- 免费开源工具不包含 Codex/模型、紫鸟、ERP 的账号或使用费用。
