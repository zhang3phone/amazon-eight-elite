亚马逊八项全能精英 v1.0

在自己的 Codex 环境使用本地紫鸟与 PostgreSQL，先取得可追溯资料，再生成分析和报告。工具源码预览版 0.2.0，能力边界见验收说明。

不预置店铺与账号 · 不修改店铺后台 · 合成测试与真实取数分别标记

一次本地任务如何完成

  1. 01
    确认环境与范围检查工具；用户登录；选择店铺与日期
  2. 02
    Codex 取数与校验在紫鸟读页面并下载；检查原件与字段
  3. 03
    入库、诊断与报告本机事务入库；候选复核；HTML 导出
自动界面取数依赖当前 Codex 的本地 Computer Use 工具，CLI 不会独立点击紫鸟。首次安装或建库先预览，确认准确目标后执行；已授权范围内的常规只读取数连续推进。

第一次安装，按这四步

1. 检查依赖

python3 -m aee doctor

Python 至少3.11；CSV 不需要第三方 Python 包；XLSX 需 openpyxl。自管理实例需 psql、initdb、pg_ctl。

2. 确认本地数据库

没有 PostgreSQL 时预览安装方案；已有实例优先复用用户确认的独立本机库。也可建立 Unix socket 隔离测试实例，不开放网络端口。

3. 先运行合成样例

使用 examples/synthetic，完成 collect → run → db-verify → export-html。报告应醒目标记“合成样例”，不能当真实经营结果。

4. 安装统一入口与八项技能

使用 install-skills 先预览目标，再明确 apply。同名技能存在就停止，不覆盖你的现有配置。

安装完成提醒：卖家精灵、SIF已有官方MCP。运行 python3 -m aee research-mcp-ui 预览，再加 --apply，打开本机浏览器密码框填写自己的Key；也可用终端隐藏输入入口。查看Key获取和连接验收步骤；不要把密钥发到聊天或GitHub。

逐条命令见 INSTALL.md；候选广告报告见 合成样例 HTML。

已验证什么，还缺什么

已完成

九个技能入口格式校验；68项回归；真实隔离 PostgreSQL 的事务入库、重复导入、失败回滚和报告重导出；本地紫鸟原生 Bulk 双工作表下载、稳定 ID 校验与独立真实库入库。合成报告完成桌面浏览器页面和排版检查。

真实取数至 HTML 已验收，优化效果仍待验证。原生 Bulk 提供活动与广告组 ID，无需按名称猜配。真实资料使用独立本机库；经营时区、归因口径和业务阈值未全部确认时仅观察。原始指标矛盾默认拦截；明确选择保留观察模式时保留原值并标记受影响对象。

数据在哪里

原始广告文件、原始行、分析结果和 HTML 都可保存在本机 PostgreSQL；本地导出文件用于查看。使用云端 Codex 时，用于分析的内容仍涉及模型服务，不承诺完全离线。

发行边界

本包不含真实店铺资料、Cookie、账号、密码、数据库配置或机器路径。免费工具不包含模型、紫鸟与 ERP 的账号和费用。跨平台与其他紫鸟版本、Homebrew 下载安装分支、真实设备断点及打印分页仍待验收。
