# 诊断、候选与人工复核

## 指标
CTR=点击/曝光；CPC=花费/点击；CVR=归因订单/点击；ACOS=花费/归因销售额；ROAS=归因销售额/花费。以汇总金额与计数重算，分母为零输出 N/A。不能把订单替换为销量单位后仍称相同 CVR。

广告花费和销售衡量归因效率，不证明真实净利或广告增量。TACoS 另需相同店铺/站点/币种/时间/商品范围的业务总销售；报表互动日与财务成交日期差异须说明。

## 可配置候选规则
阈值均由用户确认，未提供则保留观察。target_acos 用比率，例如 0.25 代表 25%，不是默认经营目标。minimum_clicks / minimum_orders 必须为正整数；zero_order_spend_limit 为本币种正数。

- 成熟点击不足 minimum_clicks：观察，不因一个订单的高 CVR 建议放量。
- 成熟订单为零，且点击与花费分别达到已配置样本线和花费线：review_negative，仍需检查相关性、产品阶段、归因和匹配范围。
- 成熟订单达到 minimum_orders：ACOS 高于已确认 target_acos 为 review_reduce_bid；低于目标为 review_expansion；相等为 maintain_review。均为待审候选，不给固定百分比或最优竞价。
- 没有足够成熟数据、没有必要阈值或缺少上下文：observe。保留实际命中/未命中条件，不将缺数归零。

目标/广告组/额外维度不明时，不把全部同词的表现混为一条可执行指令。已有否定、当前竞价、预算、动态竞价与广告位系数由当前配置另核；review_expansion 需检查是否已经存在精准投放、库存与利润承受力。

## 解释限制
- 高花费不证明预算受限；需要预算耗尽/受限记录和当前设置。
- 低 CTR/CVR 是排查信号，不能单凭报表确定主图或 Listing 有问题。
- 搜索词中的 ASIN 项与文本关键词分开人工识别；不能把 ASIN 直接作为否定关键词批量上传。
- 匹配/竞价/预算在期间内有变更时要分段复查，快照不等于历史配置。
- 活动与搜索词指标分别汇总，覆盖差异只作核对，不强制抹平，也不将两表数值相加。

## 候选行与最终报告
每项保留对象/稳定 ID、成熟与全期指标、实际阈值、命中条件、来源文件/行号、状态和必要复核。candidates.csv 供人工复核；原始明细与完整证据链见 metrics.json。最终报告区分“数据事实”“待核实解释”“建议试验”，不使用虚构置信度。

完成真实报表首轮时核对原始汇总、抽查高花费和出单词；再用另一周期或结构不同的商品验证规则，记录具体误判原因。未取得真实资料前，状态仅为合成样本测试通过/真实验证 pending。
